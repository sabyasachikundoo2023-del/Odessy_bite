# Odessybite

Order meals, snacks and drinks to your table without leaving your seat.

## Running the project locally

This project uses [Bun](https://bun.sh/) for package management and is built with TanStack Start, React, and Vite.

### Prerequisites

- Node.js / Bun installed
- Supabase instance (if using the database features)

### Setup

1. Install dependencies:
   ```bash
   bun install
   ```

2. Set up environment variables:
   Copy `.env.example` to `.env` (if applicable) and add your Supabase credentials.

3. Start the development server:
   ```bash
   bun run dev
   ```

4. Build for production:
   ```bash
   bun run build
   ```

## Tech Stack
- TanStack Start & React Router
- React
- Tailwind CSS & shadcn/ui
- Supabase (Auth, Database)
- Vite
